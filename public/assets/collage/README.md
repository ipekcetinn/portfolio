# Mixed-media collage assets

Created for this portfolio with the OpenAI built-in Imagegen tool. These are generated decorative illustrations, not historical photographs, personal photos, university archive materials, or documents from Belsis.

Each transparent PNG output was encoded to WebP at quality 90 with its original 1254 × 1254 dimensions and alpha channel preserved. Source artwork was not resized. Final assets are loaded lazily and decoded asynchronously.

## Files

- about-crt-cat.webp — wooden CRT television with a black cat on screen, aged Polaroid, torn paper and tape.
- education-campus-chip.webp — illustrative academic architecture print, microchip, and drafting-paper collage. The building is fictional and is not presented as Atılım University.
- experience-computer.webp — vintage desktop computer, terminal-like printout, and technical papers. The printout is decorative, not actual NETX source code.
- skills-electronics.webp — circuit fragments, components, vacuum tube, and typewriter labels. No ratings or skill levels are implied.
- projects-cassette.webp — cassette with a Projects label and decorative code scraps. It does not represent a completed project.
- contact-moon.webp — moon and planet engravings with astronomical chart fragments and stars.

## Prompts

The full final prompt for each asset, along with its filename and generation method, is recorded in generation-notes.json in this directory.

## Presentation

Collages occupy separate visual lanes beside the content. Rotation is applied to the image inside its reveal wrapper, preserving the existing scroll animation. On mobile, images return to the normal document flow. The original hero SVG, cat and scroll code remain unchanged.
